💡 How Thompson Sampling Works

The Problem: You have multiple tools (strategies) and need to decide which one to use. Each tool has some unknown success rate. How do you balance trying new tools (exploration) with using proven tools (exploitation)?

The Bayesian Solution: Represent each tool's success rate as a Beta distribution. Thompson Sampling samples from each distribution and picks the winner. This naturally explores uncertain tools while exploiting proven ones.

Key Insight: The uncertainty (width) of a distribution determines exploration. A narrow distribution (like Tool A with α=50, β=10) is confident, so Thompson Sampling mostly picks it. A wide distribution (like Tool C with α=2, β=1) is uncertain, so Thompson Sampling explores it more often.

Formula: E[Beta(α,β)] = α / (α+β)
Higher α → more successes → higher expected value
Higher β → more failures → lower expected value
α = β → maximum uncertainty (uniform distribution)
