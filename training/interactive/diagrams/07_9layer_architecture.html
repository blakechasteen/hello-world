🔄 HoloLoom 9-Layer Architecture

Interactive data transformation visualization | See how queries flow through all 9 layers

1
Input Processing
2-5ms

🔤 Input

Query → Text normalization & tokenization

📤 Output

ProcessedInput → ~200 bytes

🔧 Key Operation

SpinningWheel adapter converts raw input to normalized, tokenized format. Supports text, audio, images.

2
Pattern Selection
1-2ms

🎯 Input

ProcessedInput → Complexity detection

📤 Output

PatternCard → BARE|FAST|FUSED mode

🔧 Key Operation

LoomCommand analyzes query complexity and selects execution mode. Determines which components activate.

3
Temporal Control
<1ms

🎯 Input

Timestamp → Current execution time

📤 Output

TemporalWindow → Time bounds & timeout

🔧 Key Operation

ChronoTrigger establishes temporal window for memory retrieval (e.g., last 24 hours) and sets execution timeout.

4
Memory Retrieval ⚡
35-50ms

🎯 Input

TemporalWindow → Graph + vector search

📤 Output

MemoryShards → ~6KB (n=6)

🔧 Key Operation

YarnGraph combines BM25 keyword search, semantic similarity, and graph traversal to retrieve relevant memories. Bottleneck: ~40% of total time.

5
Feature Extraction
25-35ms

🎯 Input

MemoryShards → Multi-scale extraction

📤 Output

DotPlasma → ~2KB (features)

🔧 Key Operation

ResonanceShed extracts: Motifs (symbolic patterns), Embeddings (96D, 192D, 384D Matryoshka), Spectral features (graph Laplacian eigenvalues).

6
Warp Space Tensioning
8-12ms

🎯 Input

DotPlasma → Discrete features

📤 Output

TensionedThreads → ~3KB (manifold)

🔧 Key Operation

WarpSpace transforms discrete features into continuous tensor manifold. Enables neural operations on symbolic memory.

7
Decision Collapse
5-10ms

🎯 Input

TensionedThreads → Neural + Thompson

📤 Output

ActionPlan → Tool + confidence

🔧 Key Operation

ConvergenceEngine collapses probability distribution to discrete tool selection using Thompson Sampling. Neural network generates logits; Thompson balances exploration/exploitation.

8
Tool Execution
30-50ms

🎯 Input

ActionPlan → Execute tool

📤 Output

ToolResult → ~1KB (response)

🔧 Key Operation

Execute selected tool (answer, search, write, calculate, etc.) with query and retrieved context. Tool determines final response content.

9
Spacetime Construction
5ms

🎯 Input

ToolResult → Assemble output

📤 Output

Spacetime → ~10KB (provenance)

🔧 Key Operation

Spacetime constructs final output with complete trace: response, metadata, confidence, all intermediate steps. Enables reflection learning and audit trails.
