## How It Works

### 1. **Detect** (Phase 1: Classification)
**Who**: AI-powered pattern detection
**What**: 24 categories (15 AI slop + 9 ML logic bugs)
**Output**: Risk level, fix strategy, confidence

### 2. **Fix** (Phases 2-3: Neo + Sarah)
**Neo**: AST transformations (extract function, remove dead code)
**Sarah**: Template fixes (add try/except, env vars, timezones)
**Result**: Safe, syntax-preserving code transformations

### 3. **Track** (Phase 4: Deckard)
**Who**: Git integration with rollback safety
**What**: Creates commits, manages branches, enables rollback
**Safety**: Feature branches for high-risk, direct commits for low-risk

### 4. **Validate** (Phase 5: GLaDOS)
**Who**: 5-stage gauntlet
**Stages**: Syntax → Imports → Tests → Trough → Regression
**Result**: "The cake is NOT a lie" (when all pass)

### 5. **Deploy** (Phase 6: HAL)
**Who**: Production gatekeeper
**What**: Risk assessment, deployment safety
**Override**: Dave (developer) can override with warnings

### 6. **Learn** (Continuous)
**Who**: Thompson Sampling bandit
**What**: Learns optimal fix strategies from outcomes
**Result**: Gets better over time (87% → 94% fix success rate)
