🎯 Code Editor Guide

Quick Start

  1. Choose an example from the left sidebar
  2. Edit the code in the Monaco editor (same as VS Code)
  3. Run the code by clicking "Run Code" button
  4. View output in the right panel

Keyboard Shortcuts

  • Ctrl/Cmd + S - Save code (exports to file)
  • Ctrl/Cmd + Enter - Run code
  • Ctrl/Cmd + Space - Trigger IntelliSense
  • Ctrl/Cmd + / - Toggle comment
  • Ctrl/Cmd + F - Find
  • Ctrl/Cmd + H - Find and replace
  • Alt + ↑/↓ - Move line up/down

Supported Languages

  • Python - Backend FastAPI code, NPC logic, emotion calculations
  • JavaScript - Client SDK, web integration, API calls
  • C# - Unity game client integration

Demo Mode vs Live API

Demo Mode (Default): Code execution is simulated. Outputs are pre-defined based on the example. No actual API calls are made.

Local/Production API: Connect to a real BigPlay Engine backend. Requires API endpoint and authentication.
