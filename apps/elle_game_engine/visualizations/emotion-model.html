About the PAD Model

The PAD (Pleasure-Arousal-Dominance) model is a dimensional approach to emotion modeling used by BigPlay Engine. Unlike discrete emotion labels (happy, sad, angry), PAD represents emotions as points in a continuous 3D space, allowing for nuanced and realistic NPC emotional states.

The Four Dimensions

Valence (Pleasure)

How positive or negative the emotion is.

Range: -1.0 (very negative) to +1.0 (very positive)

Example: Happy (+0.7), Sad (-0.8), Neutral (0.0)

Arousal

How activated or energized the emotion is.

Range: 0.0 (calm) to 1.0 (excited)

Example: Excited (0.9), Relaxed (0.2), Alert (0.6)

Dominance

How much control the character feels.

Range: 0.0 (submissive) to 1.0 (dominant)

Example: Confident (0.8), Fearful (0.2), Neutral (0.5)

Trust (Extension)

How much the NPC trusts the player.

Range: 0.0 (distrust) to 1.0 (complete trust)

Example: Ally (0.9), Stranger (0.5), Enemy (0.1)

Why PAD?

The PAD model offers several advantages for game NPCs:

  • Smooth Transitions: Emotions can shift gradually rather than jumping between discrete states
  • Nuanced Behavior: NPCs can express complex emotions like "anxious excitement" or "bittersweet nostalgia"
  • Dynamic Responses: LLMs can interpret PAD values to generate contextually appropriate dialogue
  • Personality Modeling: Each NPC can have a baseline emotional state that reflects their personality
  • Relationship Tracking: Trust dimension builds/decays based on player actions over time

Example: Combat Encounter

When a player attacks an NPC, the emotion engine updates:

  • valence decreases (negative experience)
  • arousal increases (adrenaline spike)
  • dominance depends on combat outcome (win = increase, lose = decrease)
  • trust decreases significantly (betrayal)

Integration with LLMs

The PAD values are passed to the LLM in the system prompt:

"You are {npc_name}. Current emotional state: valence={0.3}, arousal={0.7}, dominance={0.5}, trust={0.6}. You feel slightly positive, quite energized, moderately confident, and somewhat trusting of the player."

The LLM then generates dialogue that reflects this emotional state, creating believable and consistent NPC behavior.
