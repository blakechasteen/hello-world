🎯 How the Live Demo Works

Connection Modes

  • Demo Mode (Default): Simulated WebSocket connection with pre-programmed NPC responses. No backend required.
  • Local API: Connect to BigPlay Engine running on localhost:8000. Requires local server.
  • Production: Connect to deployed BigPlay Engine. Requires production URL and authentication.

Real-Time Features

  • WebSocket Connection: Bidirectional real-time communication
  • Auto-Reconnect: Exponential backoff reconnection strategy
  • Message Buffering: Messages queued during disconnection
  • Heartbeat: Keeps connection alive (ping/pong every 30s)
  • Live Metrics: Latency, throughput, and uptime tracking
  • Emotion Updates: NPC emotions update in real-time based on conversation

Message Flow

  1. User types message and clicks "Send"
  2. Message sent via WebSocket to backend
  3. Backend processes with BigPlay Engine (LLM + emotion model)
  4. Response streamed back via WebSocket
  5. Emotion sphere updates in real-time
  6. Metrics updated (latency, message count)

Demo Mode Technical Details

In demo mode, the WebSocket client simulates a real connection:

  • Simulated WebSocket with all standard events (open, message, error, close)
  • Realistic latency simulation (100-300ms)
  • NPC responses based on keyword matching
  • Emotion changes triggered by message content
  • Full metrics tracking as if connected to real backend
