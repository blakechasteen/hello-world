USAGE
-----
For Users:
1. Open VS Code in workspace with HoloLoom
2. Extension automatically starts LSP server
3. Use commands as normal (Ctrl+Shift+P → HoloLoom: ...)
4. Get real-time completions and hover information

For Developers:
import { getLSPClient } from './extension';

const client = getLSPClient();
if (client?.isRunning()) {
    const result = await client.sendRequest('method', params);
}

TROUBLESHOOTING
---------------
Issue: LSP server fails to start
Solution: Check HoloLoom path in settings

Issue: Auto-detection fails
Solution: Set hololoom.lsp.hololoomPath manually

Issue: LSP server crashes
Solution: Ctrl+Shift+P → "HoloLoom: Restart LSP Server"

Issue: Want to disable LSP
Solution: Set "hololoom.lsp.enabled": false in settings

ROLLBACK PLAN
-------------
If issues arise, disable LSP:
{
  "hololoom.lsp.enabled": false
}

Extension will use HTTP API exclusively (original behavior).
