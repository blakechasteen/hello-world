# Zero-G Architecture Overview

## Executive Summary

**Zero-G** is a Loom-based architecture for safe, reversible data onboarding and real-time intelligence. It enables organizations to reason over immovable, legacy, or mission-critical data without migration risks.

**Core Metaphors:**
- **Loom**: Technical substrate (threads, weaving, memory, reasoning)
- **Spaceflight**: User experience (preflight, launch, orbit, EVA)

**Key Principle:** Data that cannot move stays in place. Zero-G accesses via metadata, APIs, and zero-copy patterns.
