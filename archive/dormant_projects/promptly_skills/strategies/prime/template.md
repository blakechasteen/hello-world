## Quality Checklist

Before submitting your response, ensure it meets these standards:

### Clarity
✓ Could a beginner understand the core idea?
✓ Are all terms defined?
✓ Is the structure logical and easy to follow?
✓ Are analogies used where helpful?

### Completeness
✓ Are edge cases covered?
✓ Are limitations stated?
✓ Are assumptions explicit?
✓ Is context provided?

### Accuracy
✓ Are all facts verified?
✓ Are sources cited (if applicable)?
✓ Are uncertainties acknowledged?
✓ Is jargon used correctly?

### Elegance
✓ Is it as simple as possible (but no simpler)?
✓ Is there unnecessary complexity?
✓ Could it be more concise without losing meaning?
✓ Is the structure intuitive?

### Practicality
✓ Is it actionable?
✓ Are concrete examples provided?
✓ Would this work in the real world?
✓ Are tradeoffs acknowledged?

## Quality Standards

**World-Class Output Has:**
- **Zero ambiguity** - Every sentence means exactly one thing
- **Complete coverage** - Nothing important is omitted
- **Perfect accuracy** - Every fact is correct
- **Elegant structure** - Natural flow, easy to navigate
- **Practical value** - Reader can act on it immediately

**Mediocre Output Has:**
- Vague language ("might", "could", "maybe")
- Missing edge cases
- Unverified claims
- Poor structure
- Theoretical-only focus

## Priming Questions

Before you respond, ask yourself:

2. **Could this be published?**

3. **Would I cite this in my own work?**
   - If no: What would make it citation-worthy?

4. **Will this be valuable in 5 years?**
   - If no: What makes it timeless vs timely?

5. **Is this the best possible answer?**
   - If no: How could it be improved?
