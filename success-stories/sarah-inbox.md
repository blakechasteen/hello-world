## The Solution

**Workflow**: [Inbox Triage](../workflow-gallery.md#inbox-triage)

**Setup Process** (3 minutes):
1. Click "Deploy Inbox Triage" in the workflow gallery
2. Connect her Gmail account (OAuth authentication)
3. Customize classification rules (optional)
4. Enable Slack notifications for urgent emails
5. Done!

**What the Workflow Does**:
1. **Classifies emails** into categories:
   - 🚨 URGENT - Requires immediate attention
   - 💬 RESPOND - Needs a response (routine)
   - 📁 ARCHIVE - Keep for reference
   - 🚫 SPAM - Delete

2. **Drafts responses** for routine emails using templates

3. **Sends Slack notifications** for urgent items

4. **Auto-archives** non-urgent emails

5. **Tracks metrics** on workflow dashboard
