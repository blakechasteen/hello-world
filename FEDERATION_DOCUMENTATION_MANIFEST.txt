4 CORE PROTOCOLS
================================================================================

1. SWIM Gossip Protocol (gossip.py)
   Purpose: Decentralized membership discovery
   Complexity: O(1) message overhead per node
   Detection Time: 100-500ms (tunable)
   Innovation: Suspicion mechanism prevents false positives

2. Kademlia DHT (routing.py)
   Purpose: Efficient capability-based routing
   Complexity: O(log n) routing hops
   At 1M nodes: ~20 hops maximum
   Innovation: XOR metric for mathematical properties

3. Byzantine Consensus (consensus.py)
   Purpose: Statistical verification without honest majority
   Algorithm: DS-STAR scoring (Domain, Sensibility, Temporal, Argument, Reference)
   Verification Levels: NONE (0) → LIGHT (2) → STANDARD (3) → DEEP (5) → CRITICAL (7+)
   Innovation: Works with minority honest verifiers if high-quality

4. Guild Organization (guild.py)
   Purpose: Domain-based specialization with earned trust
   Trust Evolution: STARTER → ESTABLISHED → VETERAN
   Admission Policies: OPEN → VOUCHED → VOTED → CLOSED
   Innovation: Wilson score reputation resists small sample variance
