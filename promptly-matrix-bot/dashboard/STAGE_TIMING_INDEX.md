## Common Questions

**Q: Why doesn't the chart appear?**
A: WebSocket must be connected and stages must complete. Check browser console.

**Q: What's a "bottleneck"?**
A: Any stage consuming >40% of total time. Red bars = bottleneck.

**Q: How do I optimize bottlenecks?**
A: See "Performance Optimization Tips" in the user guide or reference examples.

**Q: Can I change the 40% threshold?**
A: Yes! Edit `BOTTLENECK_THRESHOLD` on line ~28 of StageTimingChart.tsx

**Q: Does it support dark mode?**
A: Not yet - planned for Phase 2. Currently light theme only.

**Q: Can I export the data?**
A: Not built-in, but data is available in component props (future feature).
