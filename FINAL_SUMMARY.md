## 🎓 Quick Start Guide

### **Installation**

```bash
# Clone repository
git clone https://github.com/blakechasteen/hello-world
cd hello-world/Promptly

# Install dependencies
pip install -r promptly/requirements.txt

# Optional: Install advanced features
pip install -r promptly/analytics/requirements.txt
pip install -r promptly/api/requirements.txt
```

### **First Steps** (5 minutes)

```bash
# Initialize repository
promptly init

# Create your first prompt
promptly add greeting "Hello, {name}! Welcome to Promptly."

# Get the prompt
promptly get greeting

# Use a template
promptly template render summarize-text --vars '{"text": "Your text here"}'
```

### **Try the Interactive Tutorial** (15 minutes)

```bash
python examples/interactive_tutorial.py
```

### **Run E2E Demo** (10 minutes)

```bash
python examples/e2e_production_demo.py
```

### **Deploy to Production**

```bash
cd Promptly/promptly/api
./deploy.sh
```
