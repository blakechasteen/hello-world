3. ERROR HANDLING → Cross-Department Escalation
   ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
   Local Recovery:    Department retries internally
   Cross-Dept:        Department alerts affected departments
   Verification:      Catches errors, requests re-runs
   Orchestration:     Coordinates recovery, manages cascades

   Key: Direct re-run tool (logged) + Orchestration monitoring

This architecture implements Conway's Law for AI agents:
  "Agent architecture mirrors organizational structure"

The Claude SDK provides technical capabilities.
This architecture provides organizational structure.
Together: A federated agent swarm operating like a well-structured organization.

Result:
  - Context managed like budgets (declared upfront)
  - Permissions as organizational roles (scope enforcement)
  - Errors escalate through channels (dept → orch → human)
  - Sessions as institutional memory (decisions persist)
  - MCP as connective tissue (loose coupling, independent evolution)
