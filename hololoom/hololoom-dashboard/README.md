# HoloLoom Dashboard (New UX/UI)

This is the new, world-class Agent Orchestrator Dashboard for HoloLoom, built with React and Vite.

## Getting Started

1.  **Install Dependencies**:
    ```bash
    npm install
    ```

2.  **Run Development Server**:
    ```bash
    npm run dev
    ```

3.  **Open in Browser**:
    Navigate to the URL shown in the terminal (usually `http://localhost:5173`).

## Project Structure

-   `src/index.css`: Defines the global design system (variables, typography, glassmorphism).
-   `src/App.jsx`: The main application layout (Header, Sidebar, Canvas).
-   `src/App.css`: Styles for the main layout.
