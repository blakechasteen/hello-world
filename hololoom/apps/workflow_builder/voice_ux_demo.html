📖 How to Use Voice Commands

Thread Management:

  • "Create a new thread about machine learning" - Create and activate a new thread
  • "Switch to the machine learning thread" - Switch to existing thread
  • "Close the machine learning thread" - Archive a thread (requires confirmation)
  • "Summarize threads" - List all active threads with summaries

System Control:

  • "Loom, pause" or "Stop" - Stop all tasks
  • "Loom, help" or "Help" - Show help message

Conversational:

  • "What is Thompson Sampling?" - Ask questions
  • "Thanks" or "Got it" - Acknowledgments
  • Any natural statement - System responds conversationally
⚠️ Browser Support: Voice UX requires the Web Speech API (Chrome, Edge, Safari). Firefox may require enabling speech recognition in settings.
