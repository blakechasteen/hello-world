================================================================================
                          QUICK REFERENCE
================================================================================

API:
  HoloLoomWorker(mode="fast")
  ├─ execute(operation, params) → dict
  ├─ recall(query, k=5) → dict
  ├─ experience(content) → dict
  ├─ weave(query, mode="fast") → dict
  └─ close() → None

Operations:
  • "recall" - Search local memory
  • "experience" - Store new memory
  • "weave" - Execute reasoning cycle

Modes:
  • "bare" - Ultra-fast (45ms)
  • "fast" - Balanced (50-150ms) [default]
  • "fused" - Maximum quality (200-300ms)

Return Format:
  {
    "status": "success|error",
    "error": "error message (if status=error)",
    "execution_time_ms": float,
    ... operation-specific fields ...
  }
