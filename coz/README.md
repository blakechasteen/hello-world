# Coz – Cooperative Business Planning System

This folder houses the living operational framework for the Farm & Kitchen Cooperative.  
Each file represents a component of the overall system — designed to evolve, version by version.

- `BUSINESS_PLAN_DRAFT.md`: master roadmap  
- `CHANGELOG.md`: version history  
- `financials.md`: profit models & reinvestment logic  
- `kanban.csv`: task/time tracker  
- `SOP_index.md`: standard operating procedures directory  
- `inventory.md`: material & supply catalog  
- `schedule.md`: seasonal and production planning  
- `research_notes.md`: experimental and R&D log  

All files are interlinked with the broader MirrorCore ecosystem for tracking, automation, and performance analysis.
