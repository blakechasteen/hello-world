================================================================================
KEY FEATURES
================================================================================

LOW-RISK FIXES (automatic):
  - Issue detected by Trough
  - Phase 1 classifies (LOW risk, high confidence)
  - Phase 4 commits directly to main/master
  - Metadata saved automatically

HIGH-RISK FIXES (with review):
  - Issue detected by Trough
  - Phase 1 classifies (HIGH/CRITICAL risk)
  - Phase 4 creates feature branch
  - Manual review required
  - Merge after approval

ROLLBACK OPERATIONS:
  - Rollback last N commits
  - Rollback by category (all hardcoded_values fixes, etc.)
  - Rollback by file (all fixes to config.py, etc.)
  - Safe protection of pushed commits

SAFETY FEATURES:
  - Uncommitted changes detection
  - Feature branches for high-risk
  - Metadata audit trail
  - Dry-run mode for testing
  - Error handling and recovery

USAGE EXAMPLE

from xterminator import GitApplicator, RollbackManager

# Apply a fix from Phase 1 classification
applicator = GitApplicator()
result = await applicator.apply_fix(
    file_path="config.py",
    fixed_code=proposal.proposed_code,
    proposal=proposal
)

if result.success:
    print(f"Committed: {result.commit_hash[:8]}")
    print(f"File: {result.details['file']}")
    print(f"Risk: {result.details['risk']}")
    print(f"Confidence: {result.details['confidence']:.2f}")

# Later: Rollback if needed
rollback = RollbackManager()
result = await rollback.rollback_last(1)
print(f"Rolled back: {result.success}")
