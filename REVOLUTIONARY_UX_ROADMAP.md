## Executive Summary

HoloLoom represents a fundamental departure from traditional AI interfaces. While conventional systems treat UI as a "window into AI"—chat boxes, dashboards, forms that display results—HoloLoom pioneers **cognitive visualization**: an interface where the UI doesn't just display results, it IS the cognitive process made visible.

**The Core Insight**: Users don't want to "use" AI. They want to **think better**. HoloLoom becomes an extension of human cognition, a second brain that thinks visibly, learns continuously, and grows collaboratively.

### Key Differentiators

| Traditional AI UI | HoloLoom Cognitive UI |
|-------------------|----------------------|
| Input → Wait → Output | Continuous visible reasoning |
| Hidden confidence | Epistemic awareness displayed |
| Static interface | Adaptive to user patterns |
| Single-user | Multiplayer knowledge exploration |
| 2D screens | Spatial computing (AR/VR) |
| Tool you use | Mind you think with |

### 1.2 Component Architecture

**Three-Pane Philosophy**:

| Pane | Purpose | Primary Visualization | Data Source |
|------|---------|----------------------|-------------|
| **Left: Memory Palace** | Spatial knowledge navigation | Force-directed graph (WebGL) | `KG`, `AwarenessGraph` |
| **Center: Active Thinking** | Query input + live reasoning | Streaming timeline | `WeavingOrchestrator` |
| **Right: Awareness Metrics** | Always-visible system state | Tufte sparklines + gauges | `get_metrics()` |

**Key Design Principles**:
1. **No modals** — Everything is inline, expandable, dismissible
2. **No loading spinners** — Streaming updates show progress naturally
3. **No decoration** — Every visual element conveys information
4. **Keyboard-first** — Full navigation without mouse

### 5.3 Frustration Detection

Detect when users are struggling:

```python
class FrustrationDetector:
    """Detect user frustration from interaction patterns."""

    FRUSTRATION_SIGNALS = [
        # Hesitation
        ("hover_without_click", weight=0.3, threshold=3.0),  # seconds
        ("repeated_query_variants", weight=0.5, threshold=3),  # count

        # Correction attempts
        ("rapid_undo_redo", weight=0.6, threshold=5),  # per minute
        ("deleted_input", weight=0.4, threshold=3),  # count

        # Navigation confusion
        ("circular_navigation", weight=0.5, threshold=3),  # same pages
        ("help_menu_access", weight=0.7, threshold=1),  # explicit help

        # Timing
        ("session_too_short", weight=0.3, threshold=30),  # seconds
        ("session_too_long_no_result", weight=0.5, threshold=300),  # seconds
    ]

    def assess(self, user_session: Session) -> FrustrationLevel:
        score = 0.0
        for signal, weight, threshold in self.FRUSTRATION_SIGNALS:
            value = user_session.metrics.get(signal, 0)
            if value >= threshold:
                score += weight

        if score > 1.5:
            return FrustrationLevel.HIGH
        elif score > 0.8:
            return FrustrationLevel.MEDIUM
        return FrustrationLevel.LOW
```
