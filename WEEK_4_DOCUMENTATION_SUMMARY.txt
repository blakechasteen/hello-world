EXAMPLE USAGE

TROUGH - Detect AI Code Quality Issues:
```python
from trough import AISlopDetector, Language
import asyncio

detector = AISlopDetector()
code = 'password = "admin123"'  # Issue to detect

issues = asyncio.run(detector.detect_all(code, Language.PYTHON, "app.py"))
for issue in issues:
    print(f"Line {issue.line_number}: {issue.message}")
    print(f"  Fix: {issue.suggestion}")
```

BOSSPIG - Improve Business Writing:
```python
from bosspig import BossPigDetector

detector = BossPigDetector()
results = detector.analyze("We will leverage synergies ASAP...")

print(f"Quality Score: {results.metrics.quality_score:.0f}/100")
for finding in results.findings:
    print(f"  Fix: {finding.suggestion}")
```
