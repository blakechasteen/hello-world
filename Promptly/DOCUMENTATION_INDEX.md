## 🎯 Quick Reference Cards

### Installation
```bash
# Basic
pip install click PyYAML

# Full
pip install promptly[all]

# Verify
promptly --version
```

### First Project
```bash
promptly init
promptly add my_prompt "Hello, {name}!"
promptly list
```

### API Quick Start
```bash
uvicorn promptly.api.main:app
curl http://localhost:8000/health
```

### Plugin Development
```python
from promptly.plugins.base import BaseEvaluator

class MyEvaluator(BaseEvaluator):
    def evaluate(self, actual, expected, context):
        # Your logic
        return score
```
