❓ Frequently Asked Questions

Do I need to write code?
No! HoloLoom Workflow Builder v2 is completely visual. No code required. Everything is configured through the UI.
Can I test workflows before deploying?
Yes! Press Space (or click Preview button) to run your workflow with sample data. You'll see each step execute in real-time.
How long does it take to build a workflow?
Using snippets: 30 seconds. From scratch: 1-2 minutes. Complex workflows: 3-5 minutes. Compare to 10-15 minutes without v2!
What if I make a mistake?
Real-time validation catches errors immediately. Plus, Ctrl+Z undoes any change. You can't get stuck!
Can I reuse my workflows?
Yes! Export workflows as JSON (Ctrl+E). Import them later. Or save successful patterns as snippets for quick reuse.
What about complex workflows?
v2 supports up to 50+ nodes. For larger workflows, break into sub-workflows and compose them. Still faster than hand-coding!

🚀 Getting Started in 5 Minutes

Quick Path (Using Snippets)

  1. Open workflow_builder_v2.html
  2. Click 📚 Snippets button
  3. Drag "Email Notification" to canvas
  4. Click ▶️ Preview to test
  5. Done! ✓ (30 seconds)

Learning Path (From Scratch)

  1. Drag Query node from palette
  2. Drag Process node, connect to Query
  3. Notice smart suggestions (green highlight)
  4. Drag Output node, connect to Process
  5. Press Space to preview (2-3 minutes)
