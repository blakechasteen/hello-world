COMPONENT SPECIFICATIONS
================================================================================

Props Interface:
  files: FileNode[]                      Required - File tree data
  activeAgentId?: string                 Optional - Highlight agent
  onFileSelect?: (path: string) => void  Optional - Selection callback
  agentColorMap?: Record<string, string> Optional - Custom colors

FileNode Interface:
  path: string                           Full file path
  name: string                           Display name
  isDirectory: boolean                   Is this a folder?
  children?: FileNode[]                  Child nodes
  modifiedBy?: string                    Agent ID
  status: 'modified'|'read'|'created'|'deleted'
  lastModified: string                   ISO timestamp

Default Agent Colors:
  #3B82F6 (Blue)     - agent-1         #10B981 (Emerald)  - agent-2
  #F59E0B (Amber)    - agent-3         #EF4444 (Red)      - agent-4
  #8B5CF6 (Violet)   - agent-5         #EC4899 (Pink)     - agent-6
  #06B6D4 (Cyan)     - agent-7         #84CC16 (Lime)     - agent-8

Filtering:
  filterByStatus() - Filter by file status

Analysis:

  groupFilesByStatus() - Group files by status

Sorting:
  sortTreeByName() - Alphabetical sort

Path Utilities:
