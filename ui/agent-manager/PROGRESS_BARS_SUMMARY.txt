💡 KEY DESIGN DECISIONS
═════════════════════════════════════════════════════════════════════════════════

1. TUFTE-STYLE VISUALIZATION
   Focus on data, minimize decoration. Maximum data-ink ratio.

2. THREE SIMULTANEOUS METRICS
   Show step, time, and token progress at the same time.

3. GRACEFUL BUDGET HANDLING
   Hide bars when budgets not provided. No wasted space.

4. COLOR SEMANTICS
   Blue=steps, Amber=time, Purple=tokens. Meaningful colors.

5. OPTIONAL LABELS
   Minimal by default. Detailed options for when needed.

6. CSS TRANSITIONS
   Hardware-accelerated, smooth 300ms animations.

7. ACCESSIBILITY FIRST
   Full ARIA support. Color not the only indicator.

8. ZERO DEPENDENCIES
   React + Tailwind only. Lightweight and fast.
