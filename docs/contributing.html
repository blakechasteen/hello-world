Getting Started

Code of Conduct

We are committed to providing a welcoming and inspiring community for all. Please read and abide by our Code of Conduct:

  • Be respectful: Disagreements are natural, but hostility is not acceptable
  • Be inclusive: Welcome people of all backgrounds and experience levels
  • Be constructive: Focus on solving problems, not assigning blame
  • Be professional: Keep all communication professional and appropriate
  • Report violations: Contact the team at conduct@hololoom.dev

Step 1: Set Up Your Development Environment

# Clone the repository
git clone https://github.com/hololoom/hololoom.git
cd hololoom

# Create virtual environment
python3 -m venv .venv
source .venv/bin/activate  # On Windows: .venv\Scripts\activate

# Install dependencies
pip install --upgrade pip
pip install -e ".[dev]"

# Run tests
pytest HoloLoom/tests/ -v

Step 2: Create a Feature Branch

# Create and switch to a new branch
git checkout -b feature/your-feature-name

# Make your changes, commit regularly
git add .
git commit -m "Brief description of your changes"

# Push to your fork
git push origin feature/your-feature-name

Step 3: Submit a Pull Request

When you're ready to share your work:

  1. Push your branch to GitHub
  2. Click "Create Pull Request" on the GitHub website
  3. Provide a clear title and description
  4. Link any related issues
  5. Wait for code review

Code Contributions

Code Style & Standards

  • Language: Python 3.9+
  • Style Guide: PEP 8
  • Type Hints: Required for public APIs
  • Docstrings: Google style with examples
  • Line Length: 100 characters max
  • Testing: Unit tests for all new code

Code Style Example:

def calculate_similarity(embedding_a: np.ndarray, embedding_b: np.ndarray) -> float:
    """Calculate cosine similarity between two embeddings.

    Args:
        embedding_a: First embedding vector (n_dims,)
        embedding_b: Second embedding vector (n_dims,)

    Returns:
        Cosine similarity score (0.0-1.0)

    Example:
        >>> a = np.array([1.0, 0.0, 0.0])
        >>> b = np.array([1.0, 1.0, 0.0])
        >>> similarity = calculate_similarity(a, b)
        >>> print(f"{similarity:.3f}")  # 0.707
    """
    norm_a = np.linalg.norm(embedding_a)
    norm_b = np.linalg.norm(embedding_b)
    return np.dot(embedding_a, embedding_b) / (norm_a * norm_b)

Code Review Process

  1. Automated Checks: CI/CD runs tests, linting, type checks
  2. Code Review: At least 1 maintainer reviews changes
  3. Discussion: Feedback provided in comments
  4. Revisions: Make requested changes and push again
  5. Approval: Maintainer approves when satisfied
  6. Merge: PR is merged into main

What We Look For

  • Code follows style guide
  • Tests are included and passing
  • Documentation is updated
  • No unnecessary dependencies added
  • Changes are focused and atomic
  • Commit messages are clear

Writing Tests

Test Template:

import pytest
from HoloLoom.policy.unified import NeuralCore

class TestNeuralCore:
    """Test suite for NeuralCore policy module."""

    @pytest.fixture
    def core(self):
        """Fixture providing a NeuralCore instance."""
        return NeuralCore(
            mem_dim=384,
            n_tools=5,
            scales=[96, 192, 384]
        )

    def test_forward_pass(self, core):
        """Test forward pass with valid inputs."""
        features = {
            'motifs': ['test_motif'],
            'embeddings': [0.5] * 384,
        }
        logits = core(features)
        assert logits.shape == (5,)

    def test_invalid_features_raise_error(self, core):
        """Test that invalid features raise ValueError."""
        invalid_features = {'invalid': 'data'}
        with pytest.raises(ValueError):
            core(invalid_features)

Running Tests

# Run all tests
pytest HoloLoom/tests/ -v

# Run only unit tests
pytest HoloLoom/tests/unit/ -v

# Run with coverage report
pytest HoloLoom/tests/ --cov=HoloLoom --cov-report=html

# Run specific test file
pytest HoloLoom/tests/unit/test_policy.py -v

# Run with markers
pytest -m "not slow" HoloLoom/tests/
