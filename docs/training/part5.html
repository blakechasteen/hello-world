3. Embedding Computation and Caching


        
Matryoshka Multi-Scale Embeddings


        
HoloLoom uses Matryoshka embeddings - a single 384D embedding that encodes multiple scales:


        
Full embedding (384D):
├─ Finest scale: 96D (most specific, exact semantics)
├─ Medium scale: 192D (semantic + some context)
└─ Coarse scale: 384D (broad topics + relationships)


        
Advantage: One embedding, multiple retrieval qualities. Use 96D for fast similar searches, 384D for deep understanding.


        
Zero-Copy Embedding Optimization


        
Instead of multiplying matrices to extract scales, use array slicing:


        
# Traditional (slow): 37.7× slower
embedding_96d = np.matmul(full_embedding, projection_matrix_96)  # ~37ms

# Zero-copy (fast): Direct slicing
embedding_96d = full_embedding[:96]  # ~1ms ⚡

# Speedup: 37×!

4. Knowledge Graph Traversal


        
Yarn Graph Structure


        
HoloLoom's knowledge graph (Yarn Graph) uses NetworkX MultiDiGraph with typed edges:


        
Graph Structure:

Nodes:
├─ "Thompson Sampling" (entity type: CONCEPT)
├─ "Thompson" (entity type: PERSON)
├─ "Bayesian" (entity type: CONCEPT)
└─ "Exploration" (entity type: CONCEPT)

Edges (with relationship types):
├─ "Thompson Sampling" --[IS_A]→ "Bayesian Method"
├─ "Thompson Sampling" --[USES]→ "Beta Distribution"
├─ "Thompson" --[DISCOVERED]→ "Thompson Sampling"
├─ "Thompson Sampling" --[LEADS_TO]→ "Exploration Balance"
└─ ... (more relationships)


        
Multi-Hop Retrieval


        
Retrieve knowledge by following relationship paths:


        
# Start: "Thompson Sampling"
# Goal: Find related concepts 2 hops away

hop_1 = graph.get_neighbors("Thompson Sampling")
# Returns: ["Beta Distribution", "Exploration", "Bayesian"]

hop_2 = []
for neighbor in hop_1:
    neighbors_of_neighbor = graph.get_neighbors(neighbor)
    hop_2.extend(neighbors_of_neighbor)
# Returns: ["Probability", "Variance", "Reward", ...]

# Result: Ranked by relevance score


        
5. Spacetime Construction and Provenance


        
What is Spacetime?


        
Spacetime is HoloLoom's output format - a 4-dimensional response with complete provenance:


        
Spacetime = Response + Trace + Metadata + Confidence

Structure:
├─ response: str
│   └─ "Thompson Sampling balances exploration..."
│
├─ trace: List[WeavingStep]
│   ├─ Step 1: Pattern selection (FAST mode)
│   ├─ Step 2: Memory retrieval (5 shards found)
│   ├─ Step 3: Feature extraction (confidence: 0.85)
│   ├─ Step 4: Policy decision (tool: semantic_search)
│   └─ Step 5: Response generation (latency: 42ms)
│
├─ metadata: Dict
│   ├─ confidence: 0.92
│   ├─ latency_ms: 125
│   ├─ tool_used: "semantic_search"
│   ├─ sources: [shard_id_1, shard_id_2, ...]
│   └─ timestamp: "2025-11-16T10:30:45Z"
│
└─ confidence: float (0.0-1.0)
    └─ 0.92 (very confident)


        
Building the Trace


        
trace = []

# Step 1: Log pattern selection
trace.append(WeavingStep(
    name="Pattern Selection",
    duration_ms=5,
    status="SUCCESS",
    details={"mode": "FAST", "complexity": "medium"}
))

# Step 2: Log memory retrieval
trace.append(WeavingStep(
    name="Memory Retrieval",
    duration_ms=50,
    status="SUCCESS",
    details={"shards_found": 5, "query": "Thompson Sampling"}
))

# Step 3: Log feature extraction
trace.append(WeavingStep(
    name="Feature Extraction",
    duration_ms=30,
    status="SUCCESS",
    details={"confidence": 0.85}
))

# ... more steps ...

# Create Spacetime with complete trace
spacetime = Spacetime(
    response="Thompson Sampling balances...",
    trace=trace,
    confidence=0.92,
    metadata={
        "latency_ms": sum(step.duration_ms for step in trace),
        "timestamp": datetime.now(),
    }
)


        
6. Lifecycle Management and Cleanup


        
Async Context Manager Pattern


        
HoloLoom uses Python's async context managers for proper resource cleanup:


        
async with WeavingOrchestrator(cfg=config, shards=shards) as orchestrator:
    # Orchestrator initialized and ready

    spacetime = await orchestrator.weave(query)
    # Query processed

    # On exit, AUTOMATICALLY:
    # 1. Cancel background tasks
    # 2. Flush reflection buffer
    # 3. Close database connections
    # 4. Clean up temporary files
    # ✓ No manual cleanup needed!


        
Lifecycle Stages


        
Orchestrator Lifecycle:

┌────────────────────────────┐
│ __init__()                 │
│ ├─ Create memory backend   │
│ ├─ Load embeddings         │
│ ├─ Initialize policy       │
│ └─ Setup logging           │
└─────────────┬──────────────┘
              │
              ▼
┌────────────────────────────┐
│ __aenter__()               │
│ ├─ Connect to databases    │
│ ├─ Verify models loaded    │
│ ├─ Start background tasks  │
│ └─ Ready for queries!      │
└─────────────┬──────────────┘
              │
       ┌──────┴──────┐
       │             │
       ▼             ▼
   weave()        weave()
   (query 1)      (query N)
       │             │
       └──────┬──────┘
              │
              ▼
┌────────────────────────────┐
│ __aexit__()                │
│                            │
│ Step 1: Signal shutdown    │
│ └─ Set shutdown flag       │
│                            │
│ Step 2: Cancel tasks       │
│ └─ With 5-second timeout   │
│                            │
│ Step 3: Flush buffer       │
│ └─ Write metrics to disk   │
│                            │
│ Step 4: Close DB           │
│ └─ Neo4j/Qdrant cleanup    │
│                            │
│ Step 5: Clean files        │
│ └─ Remove temp files       │
│                            │
│ Step 6: Verify success     │
│ └─ Return cleanup status   │
└────────────────────────────┘


        
Shutdown Protocol


        
async def __aexit__(self, exc_type, exc_val, exc_tb):
    """Async context manager exit."""

    # Step 1: Signal shutdown
    self._shutdown_event.set()

    # Step 2: Cancel background tasks
    for task in self._background_tasks:
        task.cancel()

    # Step 3: Wait for graceful shutdown
    # (with timeout - don't hang forever)
    try:
        await asyncio.wait(self._background_tasks, timeout=5.0)
    except asyncio.TimeoutError:
        self.logger.warning("Shutdown timeout - forcing cleanup")

    # Step 4: Flush reflection buffer
    await reflection_buffer.flush()

    # Step 5: Close database connections
    await memory_backend.close()

    # Step 6: Clean up temporary files
    # (cache files, mmap files, etc.)


        
Error Handling During Shutdown


        
Even if an exception occurred in the with block, cleanup still happens:


        
async def __aexit__(self, exc_type, exc_val, exc_tb):
    """Handle exceptions during shutdown."""

    # If an exception occurred in the with block
    if exc_type is not None:
        self.logger.error(f"Exception: {exc_type.__name__}: {exc_val}")

        try:
            # Still try to cleanup (aggressive mode)
            for task in self._background_tasks:
                task.cancel()

            try:
                await asyncio.wait(self._background_tasks, timeout=2.0)
            except:
                pass  # Timeout is OK

            # Force flush (ignore errors)
            try:
                await self.reflection_buffer.flush(force=True)
            except:
                pass

        except Exception as cleanup_error:
            self.logger.error(f"Cleanup failed: {cleanup_error}")

        # Re-raise original exception
        return False

    # No exception - normal exit
    return True
