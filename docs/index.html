System Architecture

Built with modern async/await Python, React/TypeScript frontend, and protocol-based interfaces inspired by HoloLoom.

Frontend Layer (React/TypeScript)
API Gateway (FastAPI)
Core Orchestrator (Python)
Plugin Ecosystem (5 Categories)
AI Layer (Personalization & Analytics)
Data Layer (PostgreSQL, Neo4j, Qdrant, Redis)

Key Design Principles

  • ✓ Protocol-based - Type-safe interfaces, swappable implementations
  • ✓ Event-driven - Hooks system for plugin communication
  • ✓ Theme-based - Pedagogical orchestration, not just visual themes
  • ✓ Knowledge-centric - Learning represented as graphs, not just grades
  • ✓ Async-first - High performance with async/await throughout

Getting Started with Plugin Development

# Install LMS Plugin SDK
pip install lms-plugin-sdk

# Create your first plugin
lms-cli create-plugin \
  --name "my-quiz" \
  --category assessment

# Test locally
cd my-quiz
lms-cli dev

# Publish to marketplace
lms-cli build
lms-cli publish

You keep 70% of plugin revenue. See full documentation.
