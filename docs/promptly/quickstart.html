Installation

✨ 30 Seconds

Three commands and you're ready to go!

1
Install Promptly
pip install -e promptly/

Or from source:

cd promptly
pip install -e .
2
Verify Installation
python -c "from promptly import Promptly; print('Success!')"
3
Run CLI
python promptly/promptly_cli.py

Windows users: Use promptly.bat or Promptly.ps1

Your First Prompt

Create a file my_first_prompt.py:

from promptly import Promptly

# Create Promptly instance
p = Promptly()

# Add a simple prompt
p.add(
    name="hello-world",
    content="Say hello to {name} in a friendly way"
)

# Get the prompt back
prompt = p.get("hello-world")
print(f"Prompt: {prompt.content}")
print(f"Created: {prompt.created_at}")

Run it:

python my_first_prompt.py

CLI Basics

Promptly has a friendly command-line interface:

# Add a prompt
promptly add sql-optimizer "Optimize this query: {query}"

# List all prompts
promptly list

# View a prompt
promptly get sql-optimizer

# Execute a prompt
promptly execute sql-optimizer --query "SELECT * FROM users"

# Create a branch for experimentation
promptly branch feature/advanced-opts

# Commit changes
promptly commit -m "Add index hints"

# View version history
promptly log sql-optimizer

First Recursive Loop

Loops allow iterative refinement and complex reasoning:

from promptly.recursive_loops import RecursiveLoop, LoopType

# Create a refinement loop
loop = RecursiveLoop(
    loop_type=LoopType.REFINE,
    max_iterations=3,
    quality_threshold=0.85
)

# Run with your prompt
result = loop.run(
    initial_prompt="Write a summary of this article: {article}",
    llm_fn=lambda p: call_llm(p)
)

print(f"Final output: {result.final_output}")
print(f"Iterations: {result.iterations}")
print(f"Quality: {result.final_quality:.2f}")

Loop Types Explained

  • REFINE - Improve output iteratively (best for quality)
  • CRITIQUE - Generate, critique, and improve (self-feedback)
  • DECOMPOSE - Break problems into parts, solve, combine
  • VERIFY - Generate output and verify correctness
  • EXPLORE - Generate multiple solutions, compare and rank
  • HOFSTADTER - Meta-reasoning and self-referential thinking

VS Code Integration

💡 Slash Command Integration

Use Promptly features directly in VS Code with slash commands.

Install the Promptly extension from VS Code marketplace:

# Or install from source
git clone 
cd promptly-vscode
npm install
npm run compile
code --install-extension ./promptly.vsix

Available slash commands:

/review              → Review current file with Claude
/explain             → Explain selected code
/optimize-prompt     → Optimize prompt text
/remember "note"     → Save to HoloLoom memory
/recall "query"      → Query HoloLoom knowledge graph
/strategy auto       → Apply best prompting strategy
/gs                  → Git status
/gc                  → Git commit

Claude Desktop Integration

🎉 30+ MCP Tools

Use Promptly directly within Claude Desktop conversations.

Step 1: Install MCP SDK

pip install mcp

Step 2: Configure Claude Desktop

Edit your Claude Desktop config file:

macOS/Linux: ~/.config/Claude/claude_desktop_config.json

Windows: %APPDATA%\Claude\claude_desktop_config.json

{
  "mcpServers": {
    "promptly": {
      "command": "python",
      "args": [
        "/path/to/Promptly/promptly/integrations/mcp_server.py"
      ]
    }
  }
}

Step 3: Restart Claude Desktop

Close and reopen Claude Desktop. Promptly tools should now be available in conversations!

Available Tools in Claude

  • promptly_add - Create/update prompts
  • promptly_get - Retrieve prompts
  • promptly_list - List all prompts
  • promptly_skill_add - Create skills
  • promptly_execute_skill - Run skills
  • promptly_refine_iteratively - Refinement loops
  • promptly_ab_test - A/B test prompts
  • promptly_score_prompt - Auto-score quality
  • ...and 20+ more tools
