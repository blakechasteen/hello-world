Overview

Promptly is a production-ready, enterprise-grade prompt engineering platform that enables you to:

  • Compose prompts into powerful chains and pipelines
  • Define recursive loops (REFINE, CRITIQUE, DECOMPOSE, VERIFY, EXPLORE, HOFSTADTER) inspired by self-reference theory
  • Test prompts with LLM judging and A/B testing
  • Manage versions using Git-style branching and merging
  • Build skills as reusable, shareable prompt components
  • Integrate with HoloLoom for semantic memory and neural decision-making
  • Use Claude Desktop via 30+ MCP tools
  • Monitor analytics with real-time dashboards

Status: ✅ Complete and operational (October 2025). All 10 core features implemented and tested.

Quick Start

🚀 30-Second Setup

Get up and running with Promptly in just 30 seconds.

Installation

pip install -e promptly/

CLI Usage

python promptly/promptly_cli.py

# Or use shortcuts
./promptly/promptly.bat  # Windows
./promptly/Promptly.ps1  # PowerShell

Python API

from promptly import Promptly

p = Promptly()

# Chain prompts
result = p.chain([
    "Analyze this code",
    "Find bugs",
    "Suggest fixes"
])

See Quick Start guide for complete setup instructions.

Core Components

1. Prompt Composition Engine

Chain multiple prompts together to create complex reasoning flows:

result = p.chain([
    "List 5 ML topics",
    "Pick the most interesting",
    "Explain it in detail"
])

2. Recursive Loop System

6 loop types for different problem-solving approaches:

  • REFINE: Iterative quality improvement
  • CRITIQUE: Self-critique and improvement
  • DECOMPOSE: Break complex problems into parts
  • VERIFY: Generate and verify correctness
  • EXPLORE: Generate multiple solutions and compare
  • HOFSTADTER: Meta-reasoning and self-reference

3. LLM Judge

Evaluate responses using multi-criteria scoring:

from promptly.tools.llm_judge_enhanced import EnhancedLLMJudge

judge = EnhancedLLMJudge()
score = judge.evaluate(
    query="Explain AI",
    response="AI is artificial intelligence...",
    criteria=["accuracy", "clarity", "completeness"]
)

4. A/B Testing Framework

Compare prompt variations objectively:

from promptly.tools.ab_testing import ABTester

tester = ABTester()
winner = tester.compare(
    prompt_a="Explain {topic} simply",
    prompt_b="Provide detailed {topic} overview",
    test_cases=[{"topic": "ML"}, {"topic": "NLP"}]
)

5. Skill System

13 professional prompt templates for common tasks:

  • Code Reviewer

  • SQL Optimizer
  • API Designer
  • Test Generator
  • Security Auditor
  • ...and 7 more

HoloLoom Integration

Promptly bridges with HoloLoom's semantic memory system:

from promptly.integrations.hololoom_bridge import HoloLoomBridge

bridge = HoloLoomBridge()

# Query HoloLoom memory for context
result = bridge.query_with_memory(
    query="What did we discuss about MCTS?",
    context_limit=5
)

This enables:

  • Context-aware prompt enhancement using neural memory
  • Knowledge graph integration for semantic relationships
  • Persistent learning across sessions
  • Unified semantic space across both systems
