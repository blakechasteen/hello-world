⚙️ Installation

Choose your preferred installation method:

Install from PyPI

The easiest way to get started (assumes PyPI package available):

pip install hololoom torch numpy gymnasium

Next: Skip to Your First Query

Clone and Install from Source

For development or to use the latest features:

# Clone the repository git clone https://github.com/blakechasteen/mythRL cd mythRL # Create virtual environment python3 -m venv .venv source .venv/bin/activate # On Windows: .venv\Scripts\activate # Install dependencies pip install --upgrade pip pip install torch numpy gymnasium matplotlib # Optional: for full features pip install spacy sentence-transformers scipy networkx python -m spacy download en_core_web_sm

Verify installation:

python3 -c "from HoloLoom import HoloLoom; print('✓ HoloLoom installed')"

Next: Skip to Your First Query

Docker Setup (Production)

For persistent memory with Neo4j and Qdrant backends:

# From the mythRL directory docker-compose up -d # Wait for services to start (~30 seconds) docker-compose ps

Services started:

  • Neo4j Graph Database (localhost:7687)
  • Qdrant Vector Database (localhost:6333)
  • HoloLoom API (localhost:8000)

Then install Python dependencies:

python3 -m venv .venv source .venv/bin/activate pip install --upgrade pip pip install torch numpy gymnasium spacy sentence-transformers python -m spacy download en_core_web_sm

🚀 Your First Query

Write and execute your first HoloLoom query:

Step 1: Create a Python script

Create a file called first_query.py:

import asyncio from HoloLoom import HoloLoom from HoloLoom.config import Config async def main(): # Create HoloLoom instance with FAST mode async with HoloLoom(config=Config.fast()) as loom: # Your first query result = await loom.recall( "What is Thompson Sampling and why is it useful?" ) # Print the result print("\n🎯 Query Result:\n") print(f"Answer: {result.response}") print(f"\nConfidence: {result.confidence:.1%}") print(f"Memories Retrieved: {len(result.sources)}") if __name__ == "__main__": asyncio.run(main())

Step 2: Run it

PYTHONPATH=. python3 first_query.py

Step 3: See the output

You should see something like:

🎯 Query Result: Answer: Thompson Sampling is a probabilistic method for balancing exploration and exploitation in decision-making... Confidence: 89% Memories Retrieved: 5

🧠 What Just Happened?

HoloLoom's 9-layer architecture worked behind the scenes. Here's a quick overview:

1. Query Understanding

Extracts intent, entities, and semantic meaning from your question.

2. Memory Retrieval

Searches the knowledge graph using semantic similarity and keyword matching.

3. Feature Extraction

Creates multi-scale embeddings (Matryoshka) and spectral features from context.

4. Context Assembly

Combines retrieved memories into enriched context window.

5. Policy Decision

Neural network decides best response strategy using Thompson Sampling.

6. Response Generation

Synthesizes answer from context and selected strategy.

7. Quality Assurance

Validates response completeness and consistency.

8. Confidence Scoring

Calculates reliability metric (0.0-1.0) based on uncertainty quantification.

9. Reflection Learning

Logs interaction for continuous improvement and pattern discovery.

🔧 Troubleshooting

Running into issues? Check the common problems below:

ModuleNotFoundError: No module named 'HoloLoom' ▼

Cause: Python can't find the HoloLoom package.

Solutions:

  • Make sure you've installed HoloLoom: pip install hololoom
  • If installing from source, set PYTHONPATH=. before running
  • Verify virtual environment is activated: which python3 should show path inside .venv
ImportError: cannot import name 'Config' ▼

Cause: HoloLoom installed but version might be old or incomplete.

Solutions:

  • Upgrade HoloLoom: pip install --upgrade hololoom
  • If from source, make sure all files are present: ls HoloLoom/config.py
  • Clear pip cache and reinstall: pip install --no-cache-dir hololoom
The query runs but returns an empty response ▼

Cause: Memory system hasn't been initialized with knowledge.

Solutions:

  • HoloLoom comes with built-in knowledge. If empty, check if you're in the right directory
  • Add your own knowledge: await loom.experience("Your knowledge text")
  • Try a different query - some topics might not be covered
  • Check confidence score - low confidence might indicate limited matching knowledge
Query takes too long to run (slow) ▼

Cause: Using FUSED mode or system is under heavy load.

Solutions:

  • Use faster mode: Switch to Config.fast() or Config.bare()
  • Check system resources: CPU and RAM might be bottlenecks
  • Reduce memory size if using large knowledge base: See config options
  • Enable caching for repeated queries (automatic in FAST/FUSED modes)
Docker services won't start ▼

Cause: Docker not running or port conflicts.

Solutions:

  • Make sure Docker daemon is running: docker ps
  • Check for port conflicts: lsof -i :7687 (Neo4j) and lsof -i :6333 (Qdrant)
  • Try starting fresh: docker-compose down && docker-compose up -d
  • Don't have Docker? Just skip Docker setup - HoloLoom works fine with in-memory storage
Low confidence scores even for simple queries ▼

Cause: Knowledge gap or uncertain retrieval.

Solutions:

  • Train the system with relevant knowledge: await loom.experience("Your domain knowledge")
  • Try FUSED mode for higher quality: Config.fused()
  • Use refinement mode to improve: See refinement documentation
  • Reformulate the query - sometimes slight rewording helps
