  • Model sizes: tiny → large (speed/quality tradeoff)
  • Microphone input recording
  • Command-line fallback

EXAMPLE USAGE
================================================================================

Interactive Mode (Text Input):
  $ PYTHONPATH=. python elle/voice/assistant.py interactive
  You> show bread SOP
  Elle> Sourdough Bread Production, version 1.0.12...

Voice Mode (Microphone):
  $ PYTHONPATH=. python elle/voice/assistant.py voice
  🎤 Listening for wake word...
  User: Hey Elle, show bread SOP
  Elle: (speaks response)

Programmatic Usage:
  from elle.voice import VoiceAssistant
  
  assistant = VoiceAssistant(
      sop_dir="elle/sops",
      whisper_model="tiny"
  )
  await assistant.initialize()
  
  response = await assistant.process_voice_input(
      "update bread SOP: increase proofing to 50 minutes"
  )
