===============================================================================
                              KEY FEATURES
===============================================================================

Domain-Specific Policies:
  Healthcare   → 95% min confidence, LOW risk only, AST only
  Finance      → 95% min confidence, LOW risk only, AST only
  General      → 85% min confidence, LOW+MEDIUM risk, AST+Template
  Beekeeping   → 70% min confidence, LOW+MEDIUM risk, no tests required
  Internal     → 70% min confidence, LOW+MEDIUM risk, no tests required

Fix Decision Matrix:
                       LOW RISK  |  MEDIUM RISK  |  HIGH RISK    |  CRITICAL
    -------------------------------------------------------------------------------
    Very High (≥0.85)  AUTO      |  AUTO*        |  REVIEW       |  REVIEW
    High (0.70-0.85)   AUTO*     |  REVIEW       |  REVIEW       |  MANUAL
    Medium (0.55-0.70) REVIEW    |  REVIEW       |  MANUAL       |  MANUAL
    Low (<0.55)        MANUAL    |  MANUAL       |  MANUAL       |  SKIP

    * Requires test coverage

Learning Infrastructure:
  - Track every fix attempt with complete metadata
  - Record outcomes and validation details
  - Calculate confidence calibration (accuracy, over/underconfidence)
  - Collect Thompson Sampling data (α, β parameters)
  - Detect degradation (rolling window analysis)
  - Export for analysis (JSONL + JSON)

Performance:
  - Policy decision: <1ms overhead
  - Feedback recording: <1ms overhead
  - Complete pipeline: ~150ms (classification + fix + validation + learn)
  - Learning statistics: <5ms (cached aggregates)
  - Thompson data: <2ms (pre-computed)
  - Degradation detection: <3ms (rolling window)

===============================================================================
                           USAGE EXAMPLES
===============================================================================

Healthcare Department:
    from xterminator import MoonshotOrchestrator, AutofixPolicy

    policy = AutofixPolicy.conservative(domain='healthcare')
    orchestrator = MoonshotOrchestrator(policy=policy, enable_feedback=True)

    result = await orchestrator.process_issue(issue, code, path)
    # Only 95%+ confidence issues get auto-fixed
    # Complete audit trail for compliance

Beekeeping Department:
    policy = AutofixPolicy.aggressive(domain='beekeeping')
    orchestrator = MoonshotOrchestrator(policy=policy, enable_feedback=True)

    result = await orchestrator.process_issue(issue, code, path)
    # 70%+ confidence issues get auto-fixed
    # Faster iteration, less review

Learning Statistics:
    stats = orchestrator.get_learning_statistics()
    print(f"Success Rate: {stats['success_rate']:.1%}")
    print(f"Avg Confidence: {stats['avg_confidence']:.2f}")

    # Strategy performance
    for strategy, perf in stats['strategy_performance'].items():
        print(f"{strategy}: {perf['success_rate']:.1%} success")

Thompson Sampling (Phase 4):
    thompson_data = orchestrator.get_thompson_sampling_data()
    # → {'AST': {'alpha': 12, 'beta': 3, 'expected_reward': 0.80}, ...}

Degradation Detection (Phase 7):
    degradation = orchestrator.detect_degradation(window_size=20, threshold=0.10)
    if degradation['degradation_detected']:
        print(f"⚠️  ALERT: Success rate dropped to {degradation['recent_success_rate']:.1%}")
