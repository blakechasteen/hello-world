HoloLoom Documentation Search

This page demonstrates the integrated full-text search system for HoloLoom documentation. Try searching for any term from the documentation using the search box above.

How to Use Search

Quick search: Press / to focus the search box

Type to search: Results appear as you type (300ms debounce)

Navigate results: Use ↑ ↓ arrows to move through results

Open result: Press Enter or click a result

Close results: Press Escape

Try searching for: "Thompson Sampling", "knowledge graph", "weaving", "9-layer", "RAG"

Search Features

1. Full-Text Search

Search across all documentation pages including titles, headings, and body content. Results are ranked by relevance, with title matches weighted highest.

2. Keyword Matching

Search queries are tokenized (split into words) and matched against indexed content. Supports partial word matching and handles punctuation automatically.

3. Typo Tolerance

Fuzzy matching using Levenshtein distance helps find results even with spelling mistakes. Example: Searching "tompson" will still find "thompson" (with a small relevance penalty).

4. Result Highlighting

Query terms are highlighted in search results, making it easy to see why a result matched.

5. Search History

Your last 10 searches are saved to browser storage for easy access. Clear history by clicking the ⌫ button in search results.

6. Keyboard Navigation

Fully keyboard accessible. Use Tab to navigate, ↑↓ for results, Enter to select.

Integration Steps

1. Include Files

Add these lines to your HTML template:

<!-- In <head> -->
<link rel="stylesheet" href="./assets/css/search.css">

<!-- In <body> navigation -->
<div class="search-container">
  <input
    id="search-input"
    type="text"
    placeholder="Search documentation (press / to focus)"
    autocomplete="off"
    aria-label="Search documentation"
  >
  <div id="search-results"></div>
</div>

<!-- Before </body> -->
<script src="./assets/js/search.js"></script>

2. Build Search Index

Run the index generation script to create docs/data/search-index.json:

python scripts/generate-search-index.py

3. Deploy

Deploy the docs directory to your hosting (GitHub Pages, Netlify, etc.)

JavaScript API

Access Search Object

After page load, use window.hololoomSearch to interact with search:

// Get current statistics
const stats = window.hololoomSearch.getStatistics();
console.log(`Indexed ${stats.indexedPages} pages with ${stats.indexTokens} tokens`);

// Get search history
const history = window.hololoomSearch.getSearchHistory();
console.log('Recent searches:', history);

// Clear search history
window.hololoomSearch.clearSearchHistory();

// Perform search programmatically
const results = window.hololoomSearch.search('Thompson');
console.log(`Found ${results.length} results`);

// Get autocomplete suggestions
const suggestions = window.hololoomSearch.getAutocomplete('Thomp');
console.log('Suggestions:', suggestions);

Configuration

Customize search behavior:

// Modify config before searching
window.hololoomSearch.config.maxResults = 20;      // Show 20 results instead of 10
window.hololoomSearch.config.debounceDelay = 500;  // Wait 500ms after typing
window.hololoomSearch.config.maxHistorySize = 20;  // Store 20 searches instead of 10

Customization

CSS Styling

All search UI styles are customizable via CSS. Edit docs/assets/css/search.css to change colors, spacing, fonts, and layout.

Search Scoring

Adjust how search results are ranked by modifying the weight multipliers in search.js: 

const typeMultiplier = {
  'title': 3.0,    // Title matches weighted 3x
  'heading': 2.0,  // Header matches weighted 2x
  'body': 1.0      // Body matches baseline
};

Search Index

Manually edit docs/data/search-index.json to add custom pages or modify indexed content without regenerating the full index.
