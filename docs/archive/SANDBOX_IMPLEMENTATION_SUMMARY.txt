KEY FEATURES
================================================================================

Sandbox Modes:
  * NONE      - No isolation (testing/development)
  * SUBPROCESS - Basic subprocess with resource limits
  * CGROUPS   - Linux cgroups v2 + seccomp filtering
  * DOCKER    - Full Docker container isolation
  * AUTO      - Auto-detect best available (recommended)

Configuration:
  * Execution limits (timeout, memory, CPU)
  * Network policy (whitelist-based)
  * Filesystem isolation (read-only + overlay)
  * Docker-specific settings (image, network)

Resource Monitoring (<5% overhead target):
  * CPU tracking (avg/max/min)
  * Memory tracking (avg/peak)
  * I/O tracking (read/write bytes and rates)
  * Network tracking (sent/recv bytes)
  * Overhead estimation (<1% typical)

Graceful Degradation:
  * psutil (preferred, accurate system metrics)
  * /proc/self/stat (Linux fallback)
  * Basic estimation (no external dependencies)

Security:
  * Default deny principle (block by default)
  * Whitelist-based network access
  * Read-only filesystem + ephemeral writes
  * Process resource limits
  * Complete isolation options (Docker)

SECURITY PROPERTIES
================================================================================

Default Deny:
  [OK] Network disabled by default (network_enabled=False)
  [OK] Filesystem read-only by default (filesystem_readonly=True)
  [OK] All processes timeout (timeout_seconds=30.0)
  [OK] Memory limits enforced (memory_limit_mb=512)

Isolation Strength:
  * SUBPROCESS: Process-level (good for development)
  * CGROUPS:    OS-level (good for production Linux)
  * DOCKER:     Container-level (maximum isolation)

Network Control:
  * Whitelist-based (allow specific hosts/ports only)
  * DNS whitelisting (separate control)
  * System-wide filtering (via netfilter or eBPF)

Filesystem Control:
  * Read-only root with optional overlay
  * Explicit write path allowlisting
  * Ephemeral write storage (lost on cleanup)
  * Per-path access control

Resource Limits:
  * CPU: 0-100% configurable
  * Memory: 64-16384 MB configurable
  * Timeout: 1-300 seconds configurable
  * I/O: Tracked but not limited (future)
  * Network: Bandwidth not limited (future)
