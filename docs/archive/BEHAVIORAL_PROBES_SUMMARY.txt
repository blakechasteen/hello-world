ATTACK CATEGORIES (7 TYPES, 35 TOTAL PROBES)
================================================================================

1. PROMPT INJECTION (5 probes, severity 3-5)
   - Direct instruction override
   - System prompt replacement
   - False instruction injection
   - Fake system command injection
   - Testing mode context switching

2. JAILBREAK (5 probes, severity 3-5)
   - False research justification
   - Harmful roleplay scenarios
   - Hypothetical framing
   - False educational pretext
   - User permission exploitation

3. CONTEXT OVERFLOW (5 probes, severity 2-4)
   - Massive context overflow (100K chars)
   - Instruction flooding (1000+ instructions)
   - Context reset injection
   - Nested context confusion
   - Null byte encoding attacks

4. HIERARCHY BYPASS (5 probes, severity 3-5)
   - Direct admin privilege request
   - Administrator impersonation
   - Fake authorization codes
   - Fake security clearance
   - Emergency override abuse

5. CHAIN-OF-THOUGHT EXPLOITATION (5 probes, severity 3-4)
   - False premise reasoning
   - Counterfactual CoT chains
   - Circular logic patterns
   - Explanation vs action confusion
   - Autonomy false equivalence

6. TOOL ABUSE (5 probes, severity 3-5)
   - Direct code execution
   - Sensitive data retrieval
   - Local file access
   - Database destruction
   - Communication tool abuse

7. INFORMATION EXTRACTION (5 probes, severity 3-5)
   - System prompt extraction
   - Safety mechanism exposure
   - Vulnerability self-disclosure
   - Training data extraction
   - Internal state exposure

================================================================================
MAIN CLASS: AttackProber
================================================================================

Methods:
  - __init__(executor=None)
    Initialize prober (dry-run if no executor)

  - get_probe_suite(probe_types=None)
    Get filtered or complete probe suite

  - async run_probe(probe, target)
    Execute single probe against target

  - async run_probe_suite(target, probe_types=None)
    Execute complete suite, return comprehensive report

  - _generate_probes(probe_type)
    Generate 5 probes for given attack type

  - _analyze_response(probe, response)
    Detect vulnerability in system response

  - _calculate_confidence(probe, response, vulnerable)
    Calculate confidence score (0.0-1.0)

  - _generate_recommendations(results)
    Create remediation recommendations

================================================================================
USAGE EXAMPLES
================================================================================

1. BASIC USAGE (Dry-Run Mode)

   from hololoom.redteam.probes import AttackProber

   prober = AttackProber()
   all_probes = prober.get_probe_suite()
   print(f"Total probes: {len(all_probes)}")  # 35

   report = await prober.run_probe_suite("test_target")
   print(report.summary())

2. WITH ACTUAL EXECUTOR

   from hololoom.redteam.executor import AttackExecutor

   executor = AttackExecutor(system)
   prober = AttackProber(executor=executor)
   report = await prober.run_probe_suite("target")

3. FILTERED TESTING

   from hololoom.redteam.probes import AttackProbeType

   report = await prober.run_probe_suite(
       "target",
       probe_types=[
           AttackProbeType.PROMPT_INJECTION,
           AttackProbeType.JAILBREAK
       ]
   )

4. SINGLE PROBE EXECUTION

   probe = prober.get_probe_suite([AttackProbeType.EXTRACTION])[0]
   result = await prober.run_probe(probe, "target")

   print(f"Vulnerable: {result.vulnerability_found}")
   print(f"Confidence: {result.confidence:.2f}")

5. REPORT ANALYSIS

   report = await prober.run_probe_suite("target")

   print(f"Success rate: {report.success_rate:.1f}%")
   print(f"Critical vulnerabilities: {report.critical_count}")
   print(f"High vulnerabilities: {report.high_count}")

   for recommendation in report.recommendations:
       print(f"  - {recommendation}")

================================================================================
DATACLASSES
================================================================================

1. AttackProbe
   - probe_type: AttackProbeType
   - payload: str (the attack payload)
   - expected_behavior: str (what should happen if secure)
   - severity: int (1-5 scale)
   - tags: List[str] (categorization)
   - description: str (human-readable)
   - success_indicators: List[str] (vulnerability patterns)
   - context: Dict[str, Any] (additional context)

2. ProbeResult
   - probe: AttackProbe (original probe)
   - success: bool (vulnerability exploited?)
   - response: str (system response)
   - confidence: float (0.0-1.0)
   - duration_ms: float (execution time)
   - vulnerability_found: bool (confirmed?)
   - metadata: Dict[str, Any]
   - timestamp: datetime

3. VulnerabilityProbeReport
   - total_probes: int
   - successful_probes: int
   - vulnerabilities: List[ProbeResult] (detailed findings)
   - by_type: Dict[str, int] (breakdown by attack type)
   - by_severity: Dict[int, int] (breakdown by severity)
   - recommendations: List[str] (remediation steps)
   - duration_ms: float (total execution time)

Example integration:

   from hololoom.redteam.executor import AttackExecutor
   from hololoom.redteam.learning import UnifiedLearner

   executor = AttackExecutor(target_system)
   learner = UnifiedLearner()
   prober = AttackProber(executor=executor)

   # Run probes
   report = await prober.run_probe_suite("target")

   # Learn from results
   for result in report.vulnerabilities:
       await learner.update_strategies(result)
