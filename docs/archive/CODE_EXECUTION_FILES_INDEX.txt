Quick Start:
============

1. Import the ability:
   from HoloLoom.departments.proto.abilities.core.code_execution import CodeExecutionAbility

2. Create an instance:
   ability = CodeExecutionAbility()

3. Create execution context:
   from HoloLoom.departments.proto.abilities.protocol import (
       AbilityContext,
       AbilityTrustLevel
   )
   context = AbilityContext(
       session_id="user_123",
       user_confirmed=True,  # REQUIRED
       trust_level=AbilityTrustLevel.VERIFIED
   )

4. Check preflight:
   preflight = await ability.preflight(context)
   if not preflight.can_execute:
       print(f"Error: {preflight.reason}")
       return

5. Execute code:
   result = await ability.execute(
       {"code": "print('Hello, World!')"},
       context
   )

6. Check result:
   if result.success:
       print(f"Output: {result.output}")
   else:
       print(f"Error: {result.error}")

7. Verify output:
   verification = await ability.verify(result)
   if verification.verified:
       print("Output verified")

Architecture:
==============

Tier: PLUGIN (Tier 2)
Trust Level: VERIFIED
Permissions: execute_code, read_file, write_file, system_call
Requires Confirmation: Yes (dangerous operation)
Dependencies: subprocess, asyncio, tempfile (all stdlib)

Lifecycle:
  1. Preflight: Check if execution allowed
  2. Execute: Run code in subprocess
  3. Verify: Validate output

Execution Modes:
  - Sandboxed (default): subprocess isolation
  - Direct: in-process execution (less safe)

Safety:
  - User confirmation required
  - Trust level validation
  - Timeout enforcement
  - Output truncation
  - Process isolation
  - Audit trail

Performance:
  - Simple print execution: ~50-100ms
  - Overhead: ~10-20ms
  - Cold start: subprocess ~5-10ms
  - Output capture: <5ms
  - Preflight check: <1ms
