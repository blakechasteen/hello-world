================================================================================
  INTEGRATION WITH WORKFLOW BUILDER
================================================================================

To connect the gallery to the workflow builder:

STEP 1: Add "Templates" button to builder header
  Location: workflow_builder.html (canvas toolbar)
  Code: <a href="template_gallery.html" class="toolbar-btn">📋 Templates</a>

STEP 2: Add template loading logic to builder
  Location: workflow_builder.js (initialization)
  Code: Check URL parameter, load template JSON, render nodes

That's it! See INTEGRATION_GUIDE.md for complete code examples.
