DATA FLOW EXAMPLES

Flow 1: Promptly → HoloLoom (Load Prompts)
───────────────────────────────────────────

Promptly Database
    │
    │ SQL query
    ▼
PromptlyLoader.load_prompts(branch='main', tags=['production'])
    │
    │ List[Dict] (prompt data)
    ▼
PromptlyMemoryAdapter.prompts_to_shards()
    │
    │ Extract entities, motifs
    │ Add metadata
    ▼
List[MemoryShard]
    │
    ▼
HoloLoom MemoryManager
    │
    ▼
Knowledge Graph / Vector Store


Flow 2: HoloLoom → Promptly (Evaluate Prompts)
───────────────────────────────────────────────

Promptly Prompt Template
    │
    │ Format with test inputs
    ▼
HoloLoomEvaluator.evaluate_prompt()
    │
    │ Create Query object
    ▼
Feature Extraction
    │ - Embeddings (Matryoshka)
    │ - Motif detection
    │ - Spectral features
    ▼
Neural Policy (decision engine)
    │ - Cross-attention
    │ - Thompson Sampling
    │ - Tool selection
    ▼
EvaluationResult
    │ - score: 0.0-1.0
    │ - tool_selection
    │ - metadata
    ▼
Promptly Test Results / Quality Metrics

HoloLoom Side (load prompts):
─────────────────────────────

from HoloLoom.integrations.promptly import PromptlyLoader

loader = PromptlyLoader(promptly_repo_path='/path/to/repo')

# Load all prompts
shards = loader.prompts_to_shards(branch='main')

# Filter by tags/version
prompts = loader.load_prompts(
    branch='main',
    tags=['production'],
    min_version=2
)

# Load into memory
count = loader.load_into_memory(memory_manager, branch='main')

# Get metadata
metadata = loader.get_prompt_metadata('prompt_name', version=3)


Promptly Side (evaluate prompts):
──────────────────────────────────

from Promptly.promptly.integrations.hololoom import HoloLoomEvaluator

evaluator = HoloLoomEvaluator(config_mode='fast')

# Single evaluation
result = evaluator.evaluate_prompt(
    'summarizer',
    'Summarize: {text}',
    {'text': 'input'}
)

# Batch evaluation
results = evaluator.batch_evaluate(
    prompts=[...],
    test_inputs={'text': 'input'}
)

# Use in Promptly tests
from Promptly.promptly.integrations.hololoom import create_evaluator_function
hololoom_eval = create_evaluator_function(config_mode='fast')

test_cases = [{
    'inputs': {...},
    'evaluator': hololoom_eval
}]

================================================================================
CONFIGURATION EXAMPLES
================================================================================

Minimal (testing):
──────────────────

integration:
  enabled: true

hololoom:
  mode: bare  # fastest

promptly:
  default_branch: main


Balanced (production):
──────────────────────

integration:
  enabled: true
  auto_load_prompts: true

hololoom:
  mode: fast  # recommended
  memory:
    max_prompts: 100
    extract_entities: true

promptly:
  default_branch: production
  evaluation:
    use_hololoom_evaluator: true
    quality_threshold: 0.7


High-quality (evaluation):
──────────────────────────

integration:
  enabled: true

hololoom:
  mode: fused  # highest quality
  memory:
    max_prompts: 500
    extract_entities: true
    extract_motifs: true

evaluators:
  default: hololoom_neural
  hololoom_neural:
    config_mode: fused
    use_cache: true
    batch_size: 10
