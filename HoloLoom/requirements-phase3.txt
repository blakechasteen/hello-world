# ============================================================================
# Installation Notes
# ============================================================================
#
# Minimal installation (text + basic image):
#   pip install transformers torch pillow
#
# Recommended installation (all modalities):
#   pip install -r requirements-phase3.txt
#
# GPU support (for faster encoding):
#   - Install CUDA toolkit from https://developer.nvidia.com/cuda-downloads
#   - Install PyTorch with CUDA:
#     pip install torch torchvision --index-url https://download.pytorch.org/whl/cu118
#
# System requirements:
#   - RAM: 8GB minimum, 16GB recommended
#   - Storage: 5GB for models (CLIP, Whisper)
#   - GPU: Optional but recommended for video processing
#
# Model downloads:
#   - CLIP models (~350MB): Downloaded automatically on first use
#   - Whisper models (39MB-2.9GB): Downloaded automatically, size depends on model
#     - tiny: 39MB (fastest, lowest quality)
#     - base: 74MB (recommended for most use cases)
#     - small: 244MB
#     - medium: 769MB
#     - large: 2.9GB (best quality, slowest)
#
# ============================================================================
# Compatibility
# ============================================================================
#
# Python: 3.8+ (3.10+ recommended)
# OS: Linux, macOS, Windows
# Architecture: x86_64, ARM64 (Apple Silicon supported)
