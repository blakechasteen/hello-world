CORE FEATURES
================================================================================

1. DEDUPLICATION (259 lines)
   ✓ Prevents alert spam with 5-minute default window
   ✓ Key: MD5(title + severity + source_ip)
   ✓ Tracks source IPs and users per duplicate
   ✓ 4 built-in rules (SQL injection, XSS, brute force, rate limit)
   ✓ Custom rules support

2. ESCALATION (336 lines)
   ✓ Critical: Slack (0 min) → PagerDuty (15 min) → Email/SMS (30-60 min)
   ✓ Warning: Slack (0 min) → PagerDuty (30 min) → Email (60 min)
   ✓ On-call rotation integration via PagerDuty
   ✓ Time-window configuration per level
   ✓ Policy validation and summarization

3. ALERT GROUPING
   ✓ Combines related alerts within 5-minute window
   ✓ Reduces alert noise from coordinated attacks
   ✓ Unique group ID for correlation

4. ACKNOWLEDGMENT & RESOLUTION
   ✓ Stops escalation immediately on acknowledgment
   ✓ Tracks who responded and when
   ✓ Resets deduplication after resolution

5. MAINTENANCE WINDOWS
   ✓ Automatic alert suppression during scheduled maintenance
   ✓ Multiple overlapping windows supported
   ✓ Per-environment filtering (dev/staging)

6. AUDIT TRAIL
   ✓ Complete alert history with timestamps
   ✓ Who acknowledged/resolved
   ✓ Escalation timing
   ✓ Channel notification history
   ✓ Compliance-ready format

CONFIGURATION EXAMPLE
================================================================================

from HoloLoom.security.alerting import AlertingEngine, AlertSeverity, AlertConfig

config = AlertConfig(
    slack_webhook="https://hooks.slack.com/...",
    pagerduty_api_key="...",
    pagerduty_service_id="...",
    email_config={...},
    sms_config={...},
    dedup_enabled=True,
    dedup_window_seconds=300,
    escalation_enabled=True,
    grouping_enabled=True,
)

async with AlertingEngine(config) as engine:
    alert_id = await engine.alert(
        title="SQL Injection Detected",
        severity=AlertSeverity.CRITICAL,
        source_ip="192.168.1.100",
        runbook_path="security/sqli-response",
    )

    # Auto-escalates if not acknowledged within 15 minutes

QUICK START
================================================================================

1. Install & Import:
   from HoloLoom.security.alerting import AlertingEngine, AlertConfig, AlertSeverity

2. Configure:
   config = AlertConfig(slack_webhook="...")

3. Create Engine:
   async with AlertingEngine(config) as engine:

4. Send Alert:
   alert_id = await engine.alert(
       title="Alert Title",
       severity=AlertSeverity.CRITICAL,
       source_ip="192.168.1.100",
   )

5. Manage:
   await engine.acknowledge(alert_id, "user@example.com")
   await engine.resolve(alert_id, "user@example.com", reason="Fixed")
