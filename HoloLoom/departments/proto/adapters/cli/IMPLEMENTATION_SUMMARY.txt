COMMANDS
========

proto ask "question"                  Ask Proto a question
proto ask "q" --file code.py          With code context
proto repl                            Interactive REPL
proto review file.py                  Review code
proto explain file.py                 Explain code
proto --version                       Show version

============

CLI User Input
    ↓
Click/Typer Framework (sync)
    ↓
ProtoCLI class (async bridge)

ProtoEngine (lazy init)
    ↓
Query Processing
    ↓
Response Output

USAGE EXAMPLES
==============

Command line:
  $ proto ask "Explain closures"
  $ proto review slow.py
  $ proto repl

Programmatic:
  from HoloLoom.departments.proto.adapters.cli import ProtoCLI
  cli = ProtoCLI()
  result = await cli.process_query("question", "context.py")
  await cli.shutdown()

ENTRY POINT
===========

To enable 'proto' command globally, add to setup.py:

  entry_points={
      "console_scripts": [
          "proto = HoloLoom.departments.proto.adapters.cli:cli",
      ],
  },

Or use: pip install -e .
